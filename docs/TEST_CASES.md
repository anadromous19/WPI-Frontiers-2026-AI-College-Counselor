# Presentation test cases

## 1. Extracurricular suggestions
A student asks for extracurricular ideas that fit a provided profile while keeping the final decision with the student.

## 2. College support programs and accommodations
A student asks about academic support, accessibility accommodations, tutoring, mentoring, honors programs, first-generation support, and other student services.

## 3. Computer-science college visualization
A student asks for an image-based comparison/ranking of computer-science colleges using factors such as cost, admissions requirements, course quality, and employment outcomes.

**Portfolio caution:** an AI-generated chart is a demonstration output. Rankings and statistics should not be presented as authoritative unless the underlying data is independently verified.

## 4. WPI vs. Georgia Tech comparison
A student asks for a balanced infographic comparing WPI and Georgia Tech for computer science, robotics, engineering, scholarships, affordability, and overall fit.
