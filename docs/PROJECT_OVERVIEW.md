# Project overview

## Problem explored

The presentation frames the project around barriers that can reduce student interest or confidence in the college process, including lack of resources, stress and uncertainty, financial barriers, test grades, heavy workloads/lack of time, and students not feeling properly challenged.

## Proposed solution

Team built an AI-powered college-counseling chatbot intended to address student needs during the college process. A central design principle in the presentation is **"HELP, not do."**

The prototype was intended to increase engagement/motivation, reduce application-related stress, be used alongside other resources, and function as a tool rather than replace existing support.

## Personalization and interaction

The project combines a Streamlit interface, a JSON-based student profile, a system prompt with behavioral restrictions, and OpenAI API calls. The presentation also demonstrates both text and image responses.
